Unit 2: Computer Systems

Technical specifications, hardware components and workplace obligations.

1. Vocabulary: Hardware Components

Identificación técnica de los componentes internos y externos (pág. 12):

  • Monitor Visual output device.
  • Motherboard The main circuit board.
  • CPU Central Processing Unit / Processor.
  • RAM Main memory for data processing.
  • PSU Power Supply Unit.
  • Expansion Cards Video and graphic cards.
  • Optical Drive CD/DVD reader/writer.
  • Hard Disk Drive Long-term data storage.
  • Peripherals Keyboard, Mouse, Case.
2. Grammar: Comparatives

Utilizamos adjetivos comparativos para contrastar dos objetos o personas (pág. 13).

Adjective type Rule Example
Short (big, fast) Add -er (than) Your processor is faster than mine.
Long (expensive) More/Less + Adj This monitor is more expensive.
Irregular (good, bad) Better / Worse The new mouse is better than the old one.
3. Grammar: Superlatives

Para comparar un objeto dentro de un grupo (pág. 14). Siempre llevan the.

Adjective type Rule Example
Short (small, easy) The + adj + -est It is the easiest to use.
Long (reliable) The most/least + adj It has the most reliable software.
Irregular The Best / The Worst This is the best laptop in the shop.
4. Tasks: Present Continuous

Describe acciones que están ocurriendo en este momento (pág. 16).

I am installing the software now.
They aren't setting up the network today.
Are you troubleshooting the database?

Common IT Verbs: creating, inserting, running, connecting, burning.

5. Computer Usage: Must & Can

Reglas de uso de equipo y oficina (pág. 18):

Obligation (must/have to)
  • Must: I must update my files.
  • Mustn't: (Prohibición) You mustn't eat at the desk.
  • Have to: I have to log in using my password.
  • Don't have to: (No es necesario) I don't have to work at the weekend.
Ability (can/can't)
  • Can: I can use Excel.
  • Can't: I can't access some websites.

Advice: Use Should para dar sugerencias.
"You should buy a flash drive."
