Guía: Sucesiones e Inducción

Cálculo de términos generales y lógica de demostraciones matemáticas.

1. Concepto de Sucesión

Una sucesión es un conjunto ordenado de números llamados términos, donde cada lugar está designado por un subíndice (ej: a₁, a₂, a₃...).

  • Término General (aₙ): Es el criterio o fórmula que permite determinar cualquier término según su posición.
  • Subíndice (n): Indica el lugar que ocupa el término en la serie.
2. Sucesión Aritmética

Cada término se obtiene sumando al anterior un número fijo llamado Diferencia (d).

d = aⱼ - aⱼ₋₁

Cálculo del término enésimo:

aₙ = a₁ + d · (n - 1)

Nota: Para hallar el cuarto término (n=4), se sustituye n en la expresión general.

3. Sucesión Geométrica

Cada término se obtiene multiplicando al anterior por una cantidad fija llamada Razón (r).

r = aⱼ₊₁ / aⱼ

Cálculo del término general: Se obtiene operando el primer término por la razón elevada a la potencia deseada para alcanzar la posición n.

4. Clasificación según el Crecimiento
Clasificación Condición Matemática
Estrictamente Creciente aₙ₊₁ > aₙ
Creciente aₙ₊₁ ≥ aₙ
Estrictamente Decreciente aₙ₊₁ < aₙ
Decreciente aₙ₊₁ ≤ aₙ
Constante aₙ = k
Alternada Signos cambian entre (+) y (-)
5. Inducción Matemática

Método para demostrar que una propiedad P(n) es válida para todo número natural. Consta de dos pasos críticos:

  1. Base Inductiva: Demostrar que P(1) es verdadera.
  2. Paso Inductivo: Suponer que P(k) es verdadera (Hipótesis) y demostrar que implica que P(k + 1) es verdadera (Tesis).

Inducción Fuerte: Similar al anterior, pero supone que la propiedad se cumple para todos los valores h menores o iguales a k.

6. Sucesión de Fibonacci (Recursiva)

Se define recursivamente: cada término es la suma de los dos anteriores.

uₙ₊₁ = uₙ + uₙ₋₁ | Para n ≥ 2

Primeros términos: 1, 1, 2, 3, 5, 8, 13...
